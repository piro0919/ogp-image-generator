# OGP Image Generator

> Free tool to generate OGP images, favicons, and PWA icons from a single image.

Customize shape and background easily.

[🔗 Live Site](https://ogpimggen.kkweb.io)

## ✨ Features

- 🖼 Generate OGP images (1200×630) from any image
- 🎨 Customize background color and shape
- 🔖 Export favicons and PWA icons (all standard sizes)
- 📦 Download as ZIP

## 🛠 Tech Stack

- Next.js + React + TypeScript
- Tailwind CSS
- JSZip (export)

## 🚀 Development

```bash
npm install
npm run dev
```
